# NextEvent

NextEvent is a web-based Club and Event Management System developed using the MVC architecture. The application enables users to explore clubs, participate in events, and manage event applications through a secure authentication system.

## Features

- User Registration & Login
- Role-Based Authorization (Admin / User)
- Club Management (CRUD)
- Event Management (CRUD)
- Event Application System
- Application Approval & Rejection
- Event Quota Management
- Remaining Quota Display
- Duplicate Application Prevention
- Search & Filter
- Dashboard Statistics
- Responsive User Interface

## Technologies

- Node.js
- Express.js
- EJS
- Sequelize ORM
- SQLite
- Bootstrap 5
- Express Session
- Bcrypt
